# Prompt Engine

---

# Philosophy

Prompts are source code.

They must be version controlled.

They must be testable.

They must be reusable.

---

# Rules

Never write prompts inside services.

Never concatenate prompt strings randomly.

Every prompt lives inside packages/prompts.
