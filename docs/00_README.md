# Phoenix AI Studio

> AI-powered creative studio for generating high-quality Hindi comedy videos.

---

## Overview

Phoenix AI Studio is a local-first AI creative platform that helps creators generate
production-ready YouTube Shorts, Instagram Reels and short-form comedy videos.

Unlike traditional AI tools that rely on a single prompt, Phoenix AI Studio
uses a structured multi-agent workflow inspired by real movie production.

The application generates:

- Comedy concepts
- Director plans
- Stories
- Characters
- Scene breakdowns
- Dialogues
- Video prompts
- Voice scripts
- Subtitles
- Final rendered videos
