# Glossary

Version: 1.0

---

# Agent

An AI component responsible for one cognitive task.

Example

Director Agent

---

# Provider

An implementation that communicates with an external AI model.

Example

Gemini Provider

---

# Pipeline

Coordinates multiple agents.

Pipelines never think.

They orchestrate.

---

# Project

The root unit of work.

Everything belongs to a project.

---

# Series

A collection of related episodes.

---

# Episode

One story inside a series.

---

# Director Plan

Structured creative blueprint.

Generated before the story.

---

# Story

Narrative created from the Director Plan.

---

# Scene

Small visual unit.

Typically

3–8 seconds.

---

# Dialogue

Conversation between characters.

---

# Prompt

Instruction sent to an AI provider.

---

# Character

Persistent reusable entity.

Contains

Appearance

Voice

Personality

Memory

---

# Storage Service

Abstract interface for persistence.

---

# Provider Registry

Factory responsible for resolving AI providers.

---

# Workspace

The active project environment.

---

# Export

Final production-ready assets.

---

# Asset

Any generated file.

Image

Video

Audio

Subtitle

Thumbnail

Metadata

---

# Studio

The user interface of Phoenix AI Studio.
