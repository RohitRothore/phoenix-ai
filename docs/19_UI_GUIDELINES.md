# UI Guidelines

Version: 1.0

# Philosophy

Phoenix AI Studio is a Creative Studio.

It is NOT an admin dashboard.

It is NOT a CRUD application.

The interface should feel like:

• Adobe Premiere
• CapCut
• DaVinci Resolve
• Cursor
• Linear
• Notion
• Vercel Dashboard

The user should feel like they are directing a movie.
